# Data

This project uses **no external dataset**. It is a performance-analysis project: every number in the report is generated by the Monte Carlo simulator and the closed-form expressions in `../Code/src/edma_sim.py`, from the fixed physical/geometric parameters listed in `../Code/README.md` (carrier frequency, waveguide geometry, noise power, blockage parameter, target RCS).

There is accordingly nothing to download or preprocess here. To regenerate every number and figure in the report from scratch:

```bash
cd ../Code/src
rm -f sim_cache_final.npz   # optional: forces a full recompute instead of reusing the cache
python plot_v3.py
python audit_paper.py
```

This reproduces `../Results/figures/` and the checks reported in `../Results/audit_report.md`.
